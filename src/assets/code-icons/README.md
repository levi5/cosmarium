# Code file icons

SVG icons from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0),
distributed under the MIT license (see `LICENSE`).
Brand names and logos belong to their respective owners.

Assets are bundled locally so icons work without a network connection.

`text.svg`, `config.svg`, `environment.svg`, `diff.svg`, and `lock.svg` are
project-authored icons distributed under the project's MIT license.

The generic `text`, `config`, `environment`, `diff`, and `lock` symbols are
project-authored icons, not Devicon assets.
